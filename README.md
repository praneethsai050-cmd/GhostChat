## ✨ Features

- **🚀 100% Serverless GitHub Pages Ready**: Built in pure standalone HTML/CSS/JavaScript with Tailwind CSS and Lucide icons via CDN. Zero backend costs, no Node.js or VPS required.
- **⚡ Instant Matchmaking**: Public slot-based WebRTC signaling pairs two strangers randomly in seconds, or join specific private rooms with custom codes.
- **🔒 End-to-End Encryption (E2EE)**:
  - Ephemeral **ECDH (Elliptic-Curve Diffie-Hellman, P-256)** browser key agreement.
  - Authenticated **AES-256-GCM** encryption for every message and voice note.
  - Zero plaintext transmission — neither signaling brokers nor anyone in between can read your conversations.
- **🛡️ Visual Safety Fingerprint**:
  - SHA-256 hash formatted as a 6-digit verification code (`#123456`) and 4 visual emojis (`🛡️ ⚡ 🔑 🪐`).
  - Compare with your partner to confirm no man-in-the-middle (MITM) attack.
- **🎙️ Encrypted Voice Notes**:
  - Record audio in-browser via the `MediaRecorder` API.
  - Encrypted with AES-GCM before transmission, with inline audio playback and waveform progress.
- **⏳ 30-Second Disappearing Messages**:
  - All messages, system notifications, and audio notes self-destruct exactly 30 seconds after arrival.
  - Live animated progress bar visualizes expiration time.
- **⌨️ Keyboard Shortcuts & Dark UI**:
  - Press `Esc` to immediately Stop or find the Next stranger.
  - Press `Enter` to send messages.
  - Ultra-sleek dark theme inspired by modern cyberpunk aesthetics.

## 🚀 1-Click GitHub Pages Deployment

You can host **GhostChat** for free on GitHub Pages in under 60 seconds:

### Step 1: Push Repository to GitHub
Create a new public repository on GitHub (e.g. `GhostChat`), then run:

```bash
git remote add origin https://github.com/<YOUR-USERNAME>/GhostChat.git
git branch -M main
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (tab at the top).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)` or `/docs`
   - Click **Save**.
5. After ~30 seconds, your site will be live at:
   ```
   https://<YOUR-USERNAME>.github.io/GhostChat/
   ```

## 🔐 How the Cryptography Works

1. **Key Generation**: When paired, each peer creates an in-memory ephemeral ECDH keypair using curve `P-256`.
2. **Key Agreement**: Public keys are exchanged over the WebRTC Data Channel; each client computes the identical shared secret using `deriveKey`.
3. **Encryption**: Every message or voice recording is packed with an initialization vector (IV) generated by `crypto.getRandomValues(12)` and encrypted with `AES-GCM` (256-bit).
4. **Safety Fingerprint**: The raw key is digested through `SHA-256`, producing a distinct 6-digit numeric token and a unique 4-emoji fingerprint.
